--------------------------------------------------------------------------------
ACCESSING THE AGENT
--------------------------------------------------------------------------------

To access the moniple-agent API locally:

  kubectl port-forward svc/{{ include "moniple-agent.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }} -n {{ .Release.Namespace }}

Then open: http://localhost:{{ .Values.service.port }}/docs

--------------------------------------------------------------------------------
VERIFY INSTALLATION
--------------------------------------------------------------------------------

1. Check all pods are running:

   kubectl get pods -n {{ .Release.Namespace }}

2. Test the health endpoint:

   kubectl exec -it deploy/{{ include "moniple-agent.fullname" . }} -n {{ .Release.Namespace }} -- wget -qO- http://localhost:3000/health

3. Test metrics overview:

   kubectl exec -it deploy/{{ include "moniple-agent.fullname" . }} -n {{ .Release.Namespace }} -- wget -qO- http://localhost:3000/metrics/overview

{{- if index .Values "victoria-metrics" "enabled" }}

4. Check Victoria Metrics has data:

   kubectl exec -it deploy/{{ .Release.Name }}-vmsingle-server -n {{ .Release.Namespace }} -- wget -qO- 'http://localhost:8428/api/v1/query?query=up'
{{- end }}
